- Если у игры видео на выбранном языке нет (лента сломалась или канала нет),
  показываются английские этой игры.
- Сборки до этапа 6 увидят английские и японские видео вперемешку. Публичных
  выпусков не было — это касается только сборки владельца до обновления.

## 4. Перевод интерфейса

### 4.1. Словари

- `src/i18n/en.ts` — основной словарь; `src/i18n/ru.ts` — русский, объявлен
  типом английского. TypeScript не соберёт проект, если в русском чего-то нет
  или есть лишнее.
- Код обращается к полям, а не к строковым ключам: `t.panel.codes`,
  `t.play.via("Steam")`. Опечатка в имени — ошибка сборки.
- Надписи с параметрами — функции, например `via: (store) => "Launches via " + store`.
- Русский словарь — нынешние формулировки без изменений. Английские пишутся
  заново по глоссарию (§4.5).

### 4.2. Числа и даты

- Склонения — `Intl.PluralRules(locale)`: «1 day / 2 days», «1 день / 2 дня /
  5 дней».
- «5 days ago» / «5 дней назад», «yesterday» / «вчера» — `Intl.RelativeTimeFormat`
  с `numeric: "auto"`.
- Даты («data from Aug 28» / «данные от 28 августа») — `Intl.DateTimeFormat` с
  выбранным языком. Жёсткий `"ru-RU"` в `src/lib/time.ts` уходит.
- Остаток времени («3 h 52 min» / «3 ч 52 мин») — из словаря.

### 4.3. Где берётся язык

- В компонентах — хук `useT()` поверх контекста языка.
- Чистые функции в `src/lib` (`time.ts`, `panel.ts`, `launch.ts`,
  `background.ts`, `api.ts` и другие) получают словарь или язык параметром.
  Их тесты проверяют оба языка.
- Язык хранится в конфиге и читается до первой отрисовки: при запуске не
  мелькает чужой язык.
- Переключение срабатывает сразу, без перезапуска. `<html lang>` меняется
  вместе с языком.

### 4.4. Что не переводится

Названия игр; данные из вики (награды за коды, названия баннеров); заголовки
видео (они на языке, выбранном для видео); записи журнала; внутренние ошибки,
которые попадают только в журнал.

## 5. Настройки и первый запуск

### 5.1. Конфиг

- Новые поля: `language` — `"en" | "ru"`, по умолчанию `"en"`; `videoLanguage` —
  `"en" | "ja"`, по умолчанию `"en"`.
- Версия конфига остаётся 3: поля со значением по умолчанию добавляются так же,
  как `animation` на этапе 5. Нет поля — значение по умолчанию; незнакомое
  значение — тоже по умолчанию.

### 5.2. Вкладка «Вид»

В начале вкладки — блок с двуязычным заголовком «Language · Язык» (одинаковым на
обоих языках, чтобы его нашёл человек, попавший не в тот язык):

- **Interface language / Язык интерфейса** — English / Русский;
- **Video language / Язык видео** — English / 日本語.

Каждый язык подписан на самом себе. Язык видео переключается мгновенно, без
запроса в сеть: в файле данных есть оба набора.

### 5.3. Первый запуск

На экране первой настройки в углу — маленький переключатель EN / RU. Выбор
сохраняется в конфиг сразу.

## 6. Rust

### 6.1. Трей

`src-tauri/src/i18n.rs` — словарь на пункты меню («Show window / Показать окно»,
«Quit / Выход»). Меню строится на языке из конфига; при смене языка в настройках
пункты переименовываются сразу, без перезапуска.

### 6.2. Ошибки, которые видит пользователь

Команды возвращают не текст, а код и подробность:
`{ code: "gameNotFound", detail: "Genshin Impact" }`. Фразу на выбранном языке
собирает интерфейс. Известные сейчас ошибки:

| Код | Где сейчас | Нынешний текст |
|---|---|---|
| `gameNotFound` | `commands.rs` (3 места) | «нет такой игры» / «игра больше не найдена» / «игра не найдена или правка невозможна» |
| `fileMissing` | `commands.rs` (2), `launch.rs` | «файла нет: …» / «файл не найден: …» |
| `exePathMissing` | `launch.rs` | «путь к игре не задан» |
| `argsUnclosedQuote` | `launch.rs` | «не удалось разобрать аргументы…: незакрытая кавычка» |
| `exeStartFailed` | `launch.rs` | «не удалось запустить …» |
| `steamOpenFailed` | `launch.rs` | «не удалось открыть … Проверь, что Steam установлен…» |
| `epicOpenFailed` | `launch.rs` | «не удалось открыть Epic Games Launcher…» |
| `emptyTitle` | `library.rs` | «название не может быть пустым» |
| `hubUrlNotHttps` | `commands.rs` | «адрес должен начинаться с https://» |
| `videoPickFailed` | `commands.rs` | «Окну не открыть видео: …» |
| `cacheReadFailed` | `commands.rs` | «не читается кеш: …» |
| `logFolderMissing` / `openFolderFailed` | `commands.rs` | «не найдена папка журнала» / «не удалось открыть папку» |
| `configSaveFailed` | `config.rs` | ошибки записи конфига |

План проверяет каждую строку трассировкой: код получает только ошибка, которую
интерфейс показывает человеку. Ошибки кешей картинок, иконок и арта интерфейс не
показывает (там запасной рисунок) — они остаются текстом для журнала. Незнакомый
код интерфейс показывает общей фразой («Something went wrong» / «Что-то пошло не
так») с подробностью.

### 6.3. Вид запуска

Слово «напрямую» сейчас приходит из Rust (`commands.rs`, два места). Rust
отдаёт вид запуска кодом (`steam`, `epic`, `exe`, …), интерфейс пишет «Launches
via Steam» / «Запустится через Steam», «Launches directly» / «Запустится
напрямую». Названия магазинов не переводятся.

## 7. Проверка

### 7.1. Автоматическая

- Полнота словарей — проверка типов при сборке.
- **Сторож:** тест проходит по `src` и падает, если кириллица встречается
  где-либо, кроме `src/i18n/ru.ts`, комментариев и файлов тестов. Он же
  охраняет этап 7 и дальше.
- Склонения, «N days ago», даты и остаток времени — на обоих языках.
- Фильтр видео: выбранный язык; при его отсутствии — английский; видео без
  `lang` — английское.
- Rust: значения по умолчанию в конфиге (нет полей → `en`/`en`, версия 3,
  незнакомое значение → по умолчанию), словарь трея, передача кодов ошибок.
- Сборщик: источники по языкам, пометка `lang`, лимит на игру и язык.

### 7.2. Живая проверка владельца

- Первый запуск — на английском; EN / RU на экране первой настройки работает.
- Все вкладки настроек, панель, док, кнопка запуска — на обоих языках.
- Меню трея меняет язык без перезапуска.
- Японские видео у всех пяти игр; при English — английские.
- Ошибка на обоих языках — например, запуск игры с удалённым файлом.

## 8. Порядок работы

Два плана:

1. **Сборщик** — десять лент, поле `lang`, лимит на игру и язык. Выполняется
   первым, чтобы к живой проверке японские видео уже были в файле.
2. **Приложение** — словари, перевод всех экранов, настройки, первый запуск,
   трей, коды ошибок, вид запуска кодом, фильтр видео.

Приложение не зависит от сборщика жёстко: видео без `lang` — английские.

## 9. Не входит — этап 7 «Панель и трей»

- Карусель баннеров: листается сама раз в несколько секунд и плавно, стоит на
  паузе под мышью, выключается переключателем «Анимация»; стрелки слева и справа
  посередине картинки, полупрозрачные; стрелки из заголовка секции убираются.
- Будущие баннеры в карусели (данные уже приходят со сборщика).
- Автозапуск с Windows и обновление данных, когда появляется сеть.
- Запуск игры из меню трея.
- Новый README приложения.

Всё это пишется сразу на двух языках: сторож из §7.1 не пропустит русскую
строку мимо словаря.

## 10. Ограничения

- Ни одной строки `unsafe`, никаких новых зависимостей ни в приложении, ни в
  сборщике.
- Схема файла хаба — версия 2, конфиг — версия 3.
- Комментарии в коде — на русском, сообщения коммитов — на английском, всё от
  имени владельца.
