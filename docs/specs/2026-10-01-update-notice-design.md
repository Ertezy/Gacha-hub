# Gacha Hub — сообщение о новой версии и запуск с правами без PowerShell

Дата: 2026-10-01
Статус: согласовано владельцем, готово к написанию плана реализации

---

## 1. Зачем

**Новая версия.** Автообновления у приложения нет. Человек, поставивший 0.1.0,
не узнает о 0.1.1, если не зайдёт на страницу релизов сам. Приложение должно
сказать ему об этом.

**Запуск с правами.** Игры HoYoPlay требуют прав администратора; сейчас при
ошибке 740 приложение запускает их через PowerShell без окна. Это работает, но
неподписанный exe, который прячет окно PowerShell и кормит ему скрипт,
похож на то, что ищут эвристики антивирусов. Приём заменяется стандартным
механизмом Windows там, где это возможно.

## 2. Сообщение о новой версии

### 2.1. Откуда приложение узнаёт номер

Номер последней версии приходит в том же `hub.json`, который приложение и так
скачивает. Новых адресов у приложения не появляется, раздел «Приватность» не
меняется.

**Сборщик** (`Gacha-hub-info`):

- раз в 6 часов спрашивает
  `https://api.github.com/repos/Ertezy/Gacha-hub/releases/latest`
  с токеном сборки (`GITHUB_TOKEN`, если он есть) и с условным запросом
  (`If-None-Match`) — ответ 304 не тратит лимит запросов;
- этот адрес отдаёт только опубликованный релиз: черновики и пробные версии
  (`prerelease`) в ответ не попадают;
- из ответа берутся `tag_name` (без ведущей `v`) и `html_url`;
- результат хранится в памяти состояния (`appRelease`) и кладётся в файл
  каждым прогоном; сбой запроса оставляет прошлый результат и считается
  неудачей источника, как у остальных; ответ 404 (опубликованных релизов нет)
  — поля в файле нет;
- в файле: необязательное поле верхнего уровня
  `"app": { "version": "0.1.1", "url": "https://github.com/Ertezy/Gacha-hub/releases/tag/v0.1.1" }`.
  Номер версии файла остаётся 2: поле новое и необязательное, старые версии
  приложения его не замечают;
- проверка файла: `version` — три числа через точку, `url` — https.

### 2.2. Что видит пользователь

Если номер из файла **строго новее** версии приложения (сравнение трёх чисел):

- внизу боковой панели, над строкой свежести данных: «Вышла версия 0.1.1 ·
  Скачать»;
- в «Настройки → О программе» рядом с номером текущей версии: «доступна
  0.1.1 — скачать».

«Скачать» открывает в браузере `url` из файла — через тот же безопасный
переход, что и остальные ссылки (только https). Окон и всплывающих
сообщений нет, закрывать строку не нужно: после обновления она пропадает
сама.

Поле битое (не та форма, не три числа, не https) — строки нет, а остальные
данные файла читаются как обычно: из-за этого поля файл не отвергается.

## 3. Запуск с правами без PowerShell

При ошибке 740 (игре нужны права администратора):

- **аргументов запуска нет** (обычный случай) — exe открывается через
  оболочку Windows (`ShellExecuteExW`, функция `open_path` плагина opener,
  который уже есть в приложении). Windows показывает то же окно прав, что и
  при двойном клике по exe. Рабочую папку оболочка в этом случае не задаёт;
- **аргументы есть** — как сейчас, через PowerShell `Start-Process`: только он
  передаёт и аргументы, и рабочую папку;
- **пользователь нажал «Нет» в окне прав** (ошибка 1223) — это его выбор, а не
  сбой: ошибки у кнопки нет, PowerShell не пробуется;
- **оболочка отказала по другой причине** — пробуется PowerShell; если и он не
  смог, у кнопки ошибка с обеими причинами.

Новых зависимостей и `unsafe` нет. Проверка — на ноутбуке владельца с
HoYoPlay: Genshin Impact, Honkai: Star Rail и Zenless Zone Zero запускаются,
окно прав появляется, отказ в нём не показывает ошибку.
